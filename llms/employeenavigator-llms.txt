# Employee Navigator

> Employee Navigator is a benefits administration and HR software platform (Bethesda, Maryland) used by
> insurance brokers, agencies and employers to run open enrollment, new hire onboarding, ACA reporting,
> HR management, PTO tracking and integrated payroll. Its integration layer connects employer benefit
> data to 600+ insurance carriers, payroll providers, TPAs and agency management systems through EDI
> ANSI 834 files, data-exchange feeds and a partner REST API program.

## What is and is not public

Employee Navigator publishes **no public OpenAPI, no public API reference, and no self-service developer
portal.** The Company Integration API and the Company Benefit Details API — announced in 2022 and built
with Guardian Life, Principal Financial Group and other carriers — are released to partners through
Employee Navigator's technical onboarding. Prospective API partners are directed to
sales@employeenavigator.com.

What IS public and machine-readable is the OpenID Connect discovery document for the authorization
server that fronts every Employee Navigator API service. It advertises 66 scopes, and each non-standard
scope names a distinct platform API service — the clearest public map of the API surface available
without partner credentials.

Do not infer request shapes, field names, pagination, versioning, idempotency or error formats for this
provider. They are not published. Anything claiming to document them is not sourced from Employee
Navigator.

## APIs

- [Employee Navigator Identity (OpenID Connect)](https://www.employeenavigator.com/identity): OAuth 2.0 /
  OIDC authorization server (Duende IdentityServer). Supports authorization code, client credentials,
  refresh token, implicit, device code and CIBA grants; PKCE (S256); DPoP; token introspection and
  revocation; front-channel and back-channel logout.
- [Employee Navigator Partner API](https://www.employeenavigator.com/api): OAuth-protected partner REST
  service root. `GET /api/health` answers `Healthy` anonymously; every resource path requires a partner
  token.

- [EDI ANSI 834](https://www.employeenavigator.com/marketplace/product/edi-834-): the HIPAA benefit
  enrollment and maintenance transaction set; the primary carrier exchange.
